# FallGamejam2026

## How to run
Make sure to clone with the flag --recurse-submodules

1. Make sure to have these installed:
  - Zathura with pdf extension, I have only tested with mupdf
  - uv to get the correct python version

2. Run setup.sh and start_watch.sh in separate shells.

3. In the shell you ran the setup.sh script, run game.py.

When playing, make sure to always have the black window that spawned in focus,
as that is what takes the input, while the Zathura window is the game output.
